Location columnsStep 1
Turn on when the background is a web-map screenshot (Google/OSM/Leaflet, EPSG:3857) and columns are lat/lon. Leave off for plain plots, equirectangular maps, or small extents (≲3° latitude). See design doc §4.
CalibrationStep 2
Type the data value at each image edge. Values are prefilled from the data range as an approximate starting point — for accurate placement, replace them with the image's true bounds (see the test-data README for the demo values).
Place 3 spread-out reference points on the image, then type each point's data coordinates. Handles rotation & skew.
CSV coordinates are already image pixels (origin top-left, y down). No parameters needed.

Display
Fill shape keeps the base size & color; an independent open ring encodes the size variable — the two channels are visually de-linked.
Grid lines are drawn in data space through the calibration — so Mercator shows its unequal latitude spacing, and affine calibrations show tilt.
Export
Save to CSV downloads the dataset with the current calibration embedded as a reserved __PLEWMAP_CALIB__ row. Re-uploading that file auto-calibrates: location columns, the Mercator setting, and the edge values or three-point transform all restore automatically.
